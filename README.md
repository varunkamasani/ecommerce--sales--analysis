# 🛍️ E-commerce Sales Analysis

## 📊 Project Objective
Analyze e-commerce sales data from the Superstore dataset to uncover trends, identify profitable product categories and regions, and generate actionable business insights using dashboards.

## 🧰 Tools Used
- SQL (simulated in Excel)
- Excel (data cleaning & calculations)
- Tableau Public (dashboard)
- Business storytelling

## 📁 Project Structure
ecommerce-sales-analysis/ ├── data/ # Cleaned dataset ├── notebooks/ # Excel or Python logic ├── dashboard/ # Tableau dashboard (PDF/images) ├── insights/ # Summary of business insights └── README.md

## 📈 Key Business Questions
- Which product categories and regions are most profitable?
- How do discounts affect profitability?
- What sales trends occur across time?

## ✅ Outcome
- An interactive Tableau dashboard with filters and KPIs
- Business-focused summary of 3 actionable recommendations
